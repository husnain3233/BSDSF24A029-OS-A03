# BSDSF24A029-OS-A03

A custom UNIX shell built in C for the Operating Systems programming assignment.

## Build

```bash
make
```

## Run

```bash
./bin/myshell
```

## Clean

```bash
make clean
```

## Layout

- `src/` - C source files
- `include/` - headers
- `bin/` - compiled shell
- `obj/` - object files
